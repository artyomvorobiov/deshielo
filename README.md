# Deshielo — рецепты с историей

Приложение для iPhone с необычными и наглядными рецептами: фирменные блюда великих шефов, высокая кухня, рецепты из старинных книг (от вавилонских табличек 1750 года до н. э. до Молоховец), кухни мира на карте и простые блюда на каждый день.

Написано на SwiftUI, iOS 17+. Работает без интернета и без регистрации: все рецепты лежат в приложении, личные данные хранятся только на телефоне.

## Что умеет

**Контент**
- 57 рецептов в шести коллекциях: «Шефы», «Высокая кухня», «Из старинных книг», «Необычное», «Кухни мира», «На каждый день».
- У каждого блюда есть история, подробные шаги, советы, подача и сочетания.
- У исторических рецептов есть источник. Там, где оригинал перешёл в общественное достояние, приводится его текст (латынь Катона и Апиция, среднеанглийский «Формы кюри», Пушкин, Чехов) с переводом. Рядом — современная адаптация.
- 16 шефов с биографиями, 22 страны, словарь из 44 кулинарных техник, 43 кулинарных факта, сезонные продукты по месяцам.

**Фишки, которые отличают приложение**
- **Машина времени** — все датированные рецепты на шкале истории, по эпохам.
- **Кулинарный паспорт** — отмечаете приготовленное блюдо и получаете штамп страны и эпохи, плюс достижения («Историк», «Гурман без границ»…).
- **Карта вкусов** — страны с флагами на карте; уже «посещённые» выделены.
- **Из холодильника** — отмечаете, что есть дома, и получаете рецепты, для которых не хватает меньше всего; недостающее добавляется в покупки в одно нажатие.
- **Режим готовки** — крупный текст, экран не гаснет, таймеры прямо из шагов (сразу несколько), обратный отсчёт в Dynamic Island и на экране блокировки, озвучка шагов русским голосом.
- **Пересчёт порций** с «умным» округлением и русскими формами слов: «1½ зубчика», «1,25 кг».
- **Конвертер мер**: сколько граммов в стакане и ложке, старинные меры (фунт, золотник, штоф, римская либра), газовые отметки духовки.
- **Генеративные обложки**: у каждого блюда своя иллюстрация «тарелка сверху» в его цветах, у исторических — «архивная» на пергаменте с годом. Фото можно добавить в любой момент.

**Покупки и доставка**
- Список покупок раскладывается по отделам магазина. Одинаковые продукты из разных рецептов складываются (250 г + 1 кг = 1,25 кг).
- «Меню на неделю» отправляет продукты всех блюд в список одной кнопкой.
- **Заказ продуктов**: Яндекс Лавка, Самокат, ВкусВилл, Перекрёсток, Купер, Ozon fresh, Магнит. Приложение открывает поиск продукта в приложении или на сайте сервиса и заранее копирует название, чтобы его можно было вставить в поиск вручную.
- «Не хочется готовить»: поиск блюда в Яндекс Еде и ресторанов поблизости в Яндекс Картах и 2ГИС.

**Виджеты и система**
- Виджет «Рецепт дня» (3 размера и экран блокировки) — меняется каждую полночь.
- Виджет «Покупки» — интерактивный: купленное можно отметить прямо на экране «Домой».
- Виджет «Кулинарный паспорт» (в том числе круглый, для экрана блокировки).
- Таймер готовки — Live Activity в Dynamic Island.
- Siri и «Команды»: «Рецепт дня в Deshielo», «Список покупок в Deshielo», «Удиви меня в Deshielo».
- Рецепты находятся в поиске iOS (Spotlight).
- Тёмная тема и поддержка крупного шрифта.

## Как запустить — пошагово

### Что понадобится

- Mac с **Xcode 16 или новее** (лучше последний, сейчас это Xcode 26). Xcode бесплатно скачивается из Mac App Store. Старый Xcode проект не откроет.
- Для запуска на своём iPhone хватит обычного Apple ID. Платный аккаунт разработчика нужен только для TestFlight и App Store.

### 1. Скачайте проект

В Терминале:

```bash
git clone https://github.com/artyomvorobiov/deshielo.git
cd deshielo
```

Или на странице репозитория нажмите **Code → Download ZIP** и распакуйте архив.

### 2. Откройте и запустите на симуляторе

1. Дважды щёлкните `Deshielo.xcodeproj` — откроется Xcode.
2. Сверху слева выберите схему **Deshielo**, рядом — любой iPhone-симулятор (например, iPhone 17).
3. Нажмите **▶︎ (Cmd+R)**. Первая сборка займёт пару минут.

Для симулятора ни аккаунт, ни настройки не нужны. Виджеты можно добавить на экран «Домой» симулятора так же, как на настоящем телефоне.

### 3. Установите на свой iPhone

1. **Xcode → Settings → Accounts → «+» → Apple ID** — войдите своим Apple ID.
2. Откройте `Config/Shared.xcconfig` и поменяйте `BUNDLE_ID_PREFIX` на что-то уникальное, например `ru.ivanpetrov`. Это нужно, если Xcode напишет, что идентификатор уже занят. Больше нигде ничего менять не надо: идентификаторы приложения, виджетов и App Group собираются из этого префикса.
3. В навигаторе слева нажмите на проект **Deshielo**. Затем для **каждого** из таргетов `Deshielo` и `DeshieloWidgetsExtension` откройте вкладку **Signing & Capabilities** и выберите свою команду в поле **Team** (для бесплатного аккаунта это «Ваше имя (Personal Team)»).
4. Подключите iPhone кабелем и выберите его вверху вместо симулятора.
5. На iPhone включите **Настройки → Конфиденциальность и безопасность → Режим разработчика** (появится после первого подключения к Xcode), телефон перезагрузится.
6. Нажмите **▶︎**. При первом запуске iPhone может попросить доверять разработчику: **Настройки → Основные → VPN и управление устройством → ваш Apple ID → Доверять**.

С бесплатным аккаунтом приложение работает 7 дней. Потом его нужно снова запустить из Xcode — данные при этом сохраняются.

### 4. Добавьте виджеты

Долгое нажатие на экран «Домой» → **Изменить → Добавить виджет** → найдите **Deshielo** и выберите «Рецепт дня», «Покупки» или «Кулинарный паспорт». Для экрана блокировки: долгое нажатие на экран блокировки → **Настроить**.

Таймер в Dynamic Island появляется сам, когда вы запускаете таймер в шаге рецепта.

### Если что-то пошло не так

| Проблема | Что сделать |
|---|---|
| `Failed to register bundle identifier` | Поменяйте `BUNDLE_ID_PREFIX` в `Config/Shared.xcconfig` и выберите Team заново |
| Ошибка про App Group или `application-groups` | Signing & Capabilities → проверьте, что в обоих таргетах выбрана одна и та же команда. Если ошибка осталась — в `Config/Deshielo.entitlements` и `Config/DeshieloWidgets.entitlements` замените `$(APP_GROUP_IDENTIFIER)` на явную строку `group.<ваш префикс>.deshielo` |
| Виджет «Покупки» пустой, хотя список есть | Не подключена общая App Group. Проверить можно в приложении: **Моё → Настройки → Виджеты** |
| «Ненадёжный разработчик» на iPhone | Настройки → Основные → VPN и управление устройством → Доверять |
| Странные ошибки сборки после обновления Xcode | **Product → Clean Build Folder** (Shift+Cmd+K) и собрать заново |
| Нет русского голоса для озвучки | Настройки iPhone → Универсальный доступ → Устный контент → Голоса → Русский |

## Как добавить или изменить рецепт

Весь контент лежит в `Shared/Content/*.json`, код трогать не нужно. Рецепты разложены по файлам `recipes-*.json`; новый файл с таким именем подхватится автоматически.

Минимальный рецепт:

```json
{
  "id": "olivier-classic",
  "title": "Оливье по-советски",
  "summary": "Тот самый новогодний салат.",
  "story": "История блюда…",
  "collections": ["everyday"],
  "country": "RU",
  "category": "salad",
  "difficulty": 1,
  "prepMinutes": 30,
  "cookMinutes": 30,
  "servings": 6,
  "palette": ["#E8DCC0", "#9DBF6B", "#E07B54"],
  "ingredients": [
    {"name": "Картофель", "amount": 4, "unit": "pcs", "key": "potato"},
    {"name": "Соль", "unit": "toTaste", "key": "salt"}
  ],
  "steps": [
    {"title": "Отварите овощи", "text": "Отварите картофель и морковь в мундире до мягкости.", "timer": 25}
  ]
}
```

После правок проверьте контент:

```bash
python3 tools/validate_content.py
```

Скрипт найдёт опечатки в ключах продуктов, техник, стран и шефов, неверные единицы и противоречия в пометках «вегетарианское» и «без глютена». Та же проверка запускается автоматически при каждом пуше на GitHub. Все поля и правила описаны в [docs/CONTENT.md](docs/CONTENT.md).

**Фотографии.** Положите картинку в `Deshielo/Assets.xcassets` (перетащите в Xcode) и укажите её имя в поле `"image"` рецепта. Без фото рисуется генеративная обложка. Используйте только свои фото или фото со свободной лицензией.

## Как работает доставка

У сервисов доставки в России нет открытого API для добавления товаров в корзину. Поэтому приложение открывает **поиск продукта** в приложении или на сайте сервиса и заранее копирует название в буфер обмена. Если поиск не сработает, название можно просто вставить.

Адреса поиска лежат в `Shared/Content/delivery.json` (поле `searchURL`, подстановка `{query}`). Если сервис поменяет адреса, достаточно исправить строку в этом файле. Перед публикацией проверьте каждую ссылку на телефоне с установленными приложениями сервисов.

Следующий шаг — партнёрские программы: у крупных маркетплейсов и сервисов есть партнёрские ссылки, которые могут приносить доход. Подробнее — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Публикация в App Store

1. Вступите в **Apple Developer Program** (99 $ в год) на developer.apple.com. Оплатить его российской банковской картой нельзя — понадобится карта иностранного банка. Условия меняются, поэтому проверьте актуальные перед оформлением.
2. В **App Store Connect** создайте приложение с тем же Bundle ID (`<ваш префикс>.deshielo`).
3. В Xcode выберите **Any iOS Device**, затем **Product → Archive → Distribute App → App Store Connect**. Сборка появится в TestFlight — её можно раздать тестировщикам.
4. Заполните карточку: описание, скриншоты (удобно снять в симуляторе через Cmd+S), ссылку на политику конфиденциальности.
   - **Конфиденциальность**: приложение не собирает данные — всё хранится на устройстве. Выберите «Data Not Collected».
   - **Возрастной рейтинг**: в некоторых рецептах есть вино и коньяк, поэтому отметьте редкие упоминания алкоголя.
   - **Шифрование**: в проекте уже указано, что нестандартное шифрование не используется (`ITSAppUsesNonExemptEncryption = NO`).
5. Отправьте на проверку (Submit for Review). Обычно она занимает 1–3 дня.

Версия приложения и номер сборки задаются в `Config/Shared.xcconfig` (`MARKETING_VERSION`, `CURRENT_PROJECT_VERSION`). Перед каждой новой загрузкой увеличивайте номер сборки.

## Автотесты и CI

- Локально: **Product → Test (Cmd+U)**. Тесты проверяют загрузку и целостность каталога, пересчёт количеств, русские склонения, слияние списка покупок, поиск, паспорт и ссылки.
- На GitHub при каждом пуше запускается проверка контента и полная сборка с тестами на macOS (`.github/workflows/ios.yml`). Результаты — во вкладке **Actions** репозитория.

## Важно о контенте

- Рецепты шефов — домашние адаптации по мотивам их блюд, тексты написаны заново. Приложение не связано с упомянутыми шефами, ресторанами и сервисами доставки.
- Цитаты из исторических источников приводятся из текстов, перешедших в общественное достояние. Переводы и пересказы сделаны для этого приложения.
- Калорийность указана приблизительно.
