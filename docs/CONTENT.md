# Формат контента

Весь контент приложения лежит в `Shared/Content/` в виде JSON. Эти файлы попадают и в приложение, и в виджеты. Тот же набор файлов можно использовать в будущей Android-версии.

После любых правок запустите проверку:

```bash
python3 tools/validate_content.py
```

## Рецепты — `recipes-*.json`

Каждый файл — массив рецептов. Деление на файлы условное, для удобства: по коллекциям и регионам. Новый файл с именем `recipes-что-угодно.json` подхватится автоматически.

Файлы читаются по алфавиту, и в том же порядке рецепты идут в общем списке на вкладке «Рецепты». Поэтому у файлов числовые префиксы: `recipes-01-chefs.json`, `recipes-02-everyday.json` и так далее. Новый файл назовите со следующим номером — например, `recipes-16-desserts.json`.

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | Уникальный идентификатор латиницей через дефис: `beef-wellington`. Используется в ссылках и избранном — не меняйте его после публикации |
| `title` | да | Название блюда |
| `subtitle` | | Подзаголовок |
| `summary` | да | 1–2 предложения для карточек и виджета |
| `story` | да | История блюда (раздел «О блюде») |
| `collections` | | Коллекции: `chefs`, `star`, `history`, `unusual`, `everyday`. Коллекция `world` собирается сама — из всех рецептов со страной |
| `chef` | | `id` шефа из `chefs.json` |
| `country` | | ISO-код страны из `countries.json` (`FR`, `RU`…) — для карты и паспорта |
| `origin` | | Подпись происхождения: «Лион, Франция» |
| `year` | | Год появления блюда (до н. э. — отрицательный: `-1750`). По нему рецепт попадает в «Машину времени» |
| `yearLabel` | | Подпись года: «ок. 1750 до н. э.», «1880-е» |
| `category` | да | `soup`, `main`, `side`, `salad`, `dessert`, `baking`, `breakfast`, `drink`, `snack` |
| `difficulty` | да | 1 — просто, 2 — средне, 3 — сложно |
| `prepMinutes`, `cookMinutes` | да | Подготовка и готовка, минуты |
| `restMinutes` | | Ожидание: маринование, охлаждение, расстойка |
| `servings` | да | Порций в базовом рецепте |
| `calories` | | Ккал на порцию (приблизительно) |
| `diets` | | `vegetarian`, `vegan`, `gluten-free`. Проверяются автоматически по ингредиентам |
| `palette` | да | Три цвета `#RRGGBB` для обложки: основной цвет блюда, второй (соус/гарнир), акцент |
| `image` | | Имя картинки в `Assets.xcassets`. Без неё рисуется генеративная обложка |
| `ingredients` | да | Список ингредиентов (см. ниже) |
| `steps` | да | Шаги (см. ниже) |
| `plating` | | Как подавать |
| `pairing` | | С чем подавать, напитки |
| `tips` | | Список советов |
| `source` | | Исторический источник (см. ниже) |

### Ингредиент

| Поле | Описание |
|---|---|
| `name` | Название в рецепте: «Сливочное масло, очень холодное» |
| `amount` | Количество на `servings` порций. Не указывается для «по вкусу» |
| `unit` | `g`, `kg`, `ml`, `l`, `pcs` (шт.), `tbsp` (ст. л.), `tsp` (ч. л.), `pinch`, `clove`, `bunch`, `sprig`, `slice`, `leaf`, `stalk`, `head`, `toTaste` |
| `key` | Ключ продукта из `pantry.json`. Нужен для поиска «Из холодильника», отделов в списке покупок и сложения одинаковых продуктов |
| `note` | Пояснение мелким шрифтом: «нарезать кубиками» |
| `group` | Группа: «Для соуса», «Для теста». Группа «Для подачи» не учитывается в поиске «Из холодильника» |
| `optional` | `true` — по желанию. Такие продукты не попадают в покупки автоматически |

### Шаг

| Поле | Описание |
|---|---|
| `title` | Короткое действие: «Обжарьте говядину». По нему подбирается иконка шага и называется таймер |
| `text` | Подробное описание |
| `timer` | Минуты для таймера (можно дробные: `1.5`) |
| `temperature` | Температура, °C |
| `techniques` | `id` техник из `glossary.json` — по нажатию открывается объяснение |

### Источник (`source`)

| Поле | Описание |
|---|---|
| `title` | Название источника |
| `author`, `date` | Автор и дата |
| `quote` | Точная цитата на языке оригинала. Только из текстов в общественном достоянии и только если вы уверены в точности |
| `quoteLanguage` | Язык цитаты |
| `translation` | Перевод цитаты |
| `retelling` | Пересказ, если точный текст не приводится |
| `note` | Что изменено в современной адаптации |

## Справочники

| Файл | Что внутри |
|---|---|
| `pantry.json` | Продукты: `key`, название, отдел магазина (`category`), эмодзи. `staple: true` — базовые продукты (соль, масло), `fridge: false` — не показывать в «Из холодильника» |
| `collections.json` | Коллекции: название, описание, SF Symbol, цвета |
| `chefs.json` | Шефы: имя, годы, роль, биография |
| `countries.json` | Страны: код, название, описание кухни, координаты для карты |
| `eras.json` | Эпохи для «Машины времени» — диапазоны лет без пропусков |
| `glossary.json` | Словарь шефа: термин, определение, совет |
| `facts.json` | Факты дня (можно привязать к рецепту полем `recipe`) |
| `seasonal.json` | Сезонные продукты по месяцам (ключи из `pantry.json`) |
| `delivery.json` | Сервисы доставки: `homeURL`, шаблон поиска `searchURL` с `{query}`, `kind`: `groceries` / `restaurants` / `places` |
| `measures.json` | Конвертер: объёмы ложек и стаканов, плотность продуктов, старинные меры, газовые отметки духовки |

## Вино и чай — `wine.json` и `tea.json`

Справочник раздела «Вино и чай». Его тоже проверяет `tools/validate_content.py`.

**`wine.json`** — объект с массивами `styles`, `grapes`, `regions` и блоком `fallback`:

| Что | Поля |
|---|---|
| Стиль (`styles`) | `id`, `name`, `summary`, `description`, `serving` (температура подачи), `glass` (бокал), `palette` (три цвета для иллюстрации), `pairing` (правило подбора, см. ниже) |
| Сорт (`grapes`) | `id`, `name`, `original` (название в оригинале), `color`: `red` или `white`, `body`, `acidity`, `tannin` — от 1 до 5, `aromas`, `summary`, `story`, `styles` и `regions` (ссылки по `id`), `vivino` (запрос для поиска в Vivino), `palette` |
| Регион (`regions`) | `id`, `name`, `original`, `country` (ISO-код, страны может не быть в `countries.json`), `lat`, `lon`, `summary`, `story`, `grapes`, `vivino` |

Сорт и регион ссылаются друг на друга: если у сорта указан регион, у региона должен быть указан этот сорт. `fallback.sweets` — стиль для сладких блюд, к которым не подошло ни одно правило.

**`tea.json`** — объект с массивами `types`, `teas` и блоком `fallback`:

| Что | Поля |
|---|---|
| Тип (`types`) | `id`, `name`, `oxidation` (степень окисления), `summary`, `description`, `palette`, `brewing` |
| Чай (`teas`) | `id`, `name`, `original`, `type` (`id` типа), `origin` (где растёт), `country`, `lat`, `lon`, `aromas`, `summary`, `story`, `brewing`, `palette`, `pairing`, `recipe` (необязательно: `id` рецепта с этим чаем) |
| Заваривание (`brewing`) | `temperature` (°C, 50–100), `grams`, `water` (мл), `steeps` — время проливов в секундах; каждый пролив в приложении запускает таймер. Если чай не настаивают (матча), `steeps` пустой, а способ описан в `note` |

`fallback` у чая — запасной чай по категории блюда (`breakfast`) и для сладкого (`sweets`).

### Правило подбора (`pairing`)

| Поле | Описание |
|---|---|
| `keys` | Продукты из `pantry.json`, с которыми напиток сочетается |
| `categories` | Категории блюд |
| `countries` | Кухни: местный напиток к местной еде |
| `techniques` | Техники из `glossary.json` |
| `avoid` | Продукты, с которыми напиток не дружит |
| `sweets` | `true` — правило для сладкого: десертов и сладкой выпечки |
| `note` | Почему это работает — показывается в рецепте |

Как считается подбор (код — `Deshielo/Drinks/DrinkPairing.swift`):

- учитываются обязательные ингредиенты рецепта, кроме базовых (`staple`) и группы «Для подачи»;
- продукт из `keys` даёт 3 очка, если он среди четырёх главных ингредиентов, иначе 2. Мука, масло, яйца, молоко, лук, чеснок, дрожжи, разрыхлитель и крахмал главными не считаются. В зачёт идут три лучших совпадения;
- категория даёт +2, страна +3, техника +1, продукт из `avoid` — −5;
- напиток советуется, если набрал от 3 очков. При равенстве выигрывает напиток той же страны, что и блюдо, затем — тот, что раньше в файле;
- сладкое блюдо — это десерт или выпечка, где от 50 г сахара, мёда, варенья или сгущёнки (или есть шоколад). К нему подходят только правила с `sweets: true`, к остальным блюдам — только без него;
- вино не советуется к завтракам и напиткам, чай — к напиткам.

Меняя правила, проверяйте результат на всём каталоге: удобнее всего — тестами `DrinkPairingTests` и страницами стилей и чаёв, где видно, к каким блюдам они попали.

## Советы

- **Палитра.** Возьмите цвета с хорошего фото блюда. Первый цвет — основной цвет блюда, второй — соус или гарнир, третий — акцент (зелень, ягоды). Если первый цвет очень светлый (пюре, крем), обложка автоматически кладёт блюдо на тёмную тарелку.
- **Исторические рецепты.** Добавляйте их в коллекцию `history` и указывайте `year` — тогда у обложки будет «архивный» стиль, а рецепт появится в «Машине времени».
- **Шефы.** Пишите текст рецепта своими словами: список ингредиентов и идея блюда не охраняются авторским правом, а тексты из книг и сайтов — охраняются.
